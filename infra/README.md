# 🏗️ OpenShelves Infrastructure

*Every library needs a building. This is where we'll draw the plans.*

[← Project README](../README.md)

This folder will hold the infrastructure as code for OpenShelves: everything needed to stand up the database, the API and the web app somewhere other than a laptop, written down so it can be reviewed, repeated and rebuilt.

> [!NOTE]
> **Not started yet.** For now OpenShelves runs locally only; see [Getting started](../README.md#-first-pages--getting-started).
>
> If you have experience deploying apps like this and would like to shape how it's done, [open a discussion or an issue](../CONTRIBUTING.md). This is a good place to make your mark early.
